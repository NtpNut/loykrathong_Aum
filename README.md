# ลอยกระทงด้วยกัน · อุ้ม & นัท 🌕🪷

เกมลอยกระทงออนไลน์สำหรับ 2 คน (อุ้ม และ นัท) เล่นพร้อมกันแบบ Real-time ผ่าน Firebase Realtime Database

| เวอร์ชัน | ไฟล์ | ลิงก์บน Netlify |
|---|---|---|
| 2D (สำรอง เบากว่า) | `index.html` | `/` |
| 3D (หลัก) | `3d/index.html` | `/3d/` |

## ฟีเจอร์
- เลือกตัวละคร อุ้ม / นัท และโหมดทดลองเล่นคนเดียว
- 6 สถานที่: วัดอรุณฯ, สะพานพระราม 8, สวนลุมพินี (กรุงเทพฯ) · เขื่อนขุนด่านปราการชล, น้ำตกช่องลม (นครนายก) · ท่าน้ำบ้านเรา
- แต่งกระทง (ฐาน, ดอกไม้ 6 แบบ, ของประดับ, เล็บ/ผม/เหรียญ), คำอธิษฐาน (ซ่อนได้), ข้อความถึงอีกคน
- 3D: ร้านกระทง, เดินด้วยจอยสติ๊ก/WASD, กระโดด ต่อย เตะ, ลอยเองหรือลอยพร้อมกัน
- แชต (เก็บ 40 ข้อความล่าสุด), ส่งหัวใจ, พลุ โคมลอย การ์ดตอนจบ

## ทดสอบ
ต่อท้ายลิงก์ด้วย `?room=test` เพื่อแยกข้อมูลทดสอบออกจากห้องจริง

## Deploy
ไม่มีขั้นตอน build — Netlify เผยแพร่ไฟล์ในโฟลเดอร์รากของ repo ได้ทันที (Build command: ว่าง, Publish directory: `/`)
